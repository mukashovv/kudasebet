# Фотографии себетов

Загружайте в эту папку фотографии через GitHub и указывайте в колонке «Фото» имя файла:

- `s` — сайт ищет `s.jpg`, `s.jpeg`, `s.png`, `s.webp`, `s.avif`, затем варианты с расширениями в верхнем регистре.
- `s.png` — сайт использует конкретный файл.
- `s, s2, s3.png` — несколько фотографий в указанном порядке. Для каждого имени без расширения сайт ищет подходящий формат отдельно. Первое найденное фото становится обложкой; в карточке себета доступны все найденные фотографии, миниатюры/кнопки выбора и свайп. Пробелы и пустые элементы между запятыми игнорируются, повторы и ненайденные фотографии пропускаются.

Регистр имени должен совпадать с файлом. При замене фотографии используйте новое имя, например `s-2`, и обновите колонку «Фото», чтобы браузеры сразу получили новую версию. Изменения файлов становятся доступны после публикации GitHub Pages.

Пустая колонка «Фото» показывает фото Себета S для любого себета. В галерее оно повторяется в трёх слайдах, которые можно листать. Если заполнены имена, но ни один файл не найден, отображается одно фото Себета S.

Колонка «Доступен»: `Да` включает покупку, `Нет` или пустая ячейка оставляет «Скоро». Для строк «Часто заказывают» доступность и код берутся из основной строки себета с тем же названием.

Колонка «Код»: постоянный уникальный код, например `kyrgyz-apaga`, используется в ссылке `product.html?item=kyrgyz-apaga`. Если код пустой, ссылка генерируется из названия. При изменении названия такая ссылка изменится; заполненный код сохраняет ссылку.
